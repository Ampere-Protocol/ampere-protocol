# ampere-protocol

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

SDK documentation:

```bash
cat SDK.md
```

Tests:

```bash
bun test
```

This project was created using `bun init` in bun v1.2.17. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
